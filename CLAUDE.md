# Partner pannel

Локальная демонстрационная витрина партнёрских сервисов VTB Kazakhstan.
Клиент входит в демо-копию VTB Business, изучает шесть карточек сервисов и по
кнопке «Подключить» переходит на сайт партнёра. Переход не оформляет договор
и не активирует услугу.

**Источник истины — `docs/BT.md` (версия 1.0, согласована).** Требования имеют ID
(AUTH-01, CARD-02, AI-05, AC07 и т. д.). Ссылайся на ID, а не пересказывай БТ.
Изменения требований фиксируются в БТ до реализации функции.

## Стек

React 18 + TypeScript + Vite, собственные стили (`src/styles.css`, один файл).
Сервер — Express на Node.js с `--experimental-strip-types`, без сборки TS.
Node 22+ обязателен. Иконки — `lucide-react`.

## Команды

```
npm run dev        # сервер :3001 + vite :5173 одной командой
npm run dev:web    # только фронтенд
npm run dev:api    # только сервер, с --watch
npm run build      # tsc --noEmit && vite build
npm test           # node --test, 3 теста
npm start          # прод-режим, раздаёт dist/
```

Вход: **klim / klim**. Стартовый URL — `/`, редиректит на `/login/ru.html`.

## Конвенции

- Код написан плотно, длинными строками. Не переформатируй файлы целиком —
  правь точечно, иначе diff станет нечитаемым.
- Стили — обычный CSS в `src/styles.css`, без Tailwind и CSS-in-JS.
- Тексты интерфейса на русском.
- Данные о сервисах меняются только в `server/catalog.ts`; фронтенд их не хардкодит.

## Границы, которые нельзя нарушать

- **Ключи.** `OPENAI_API_KEY` живёт только в `.env` (в `.gitignore`). Никогда не
  вписывать ключ в код, `.env.example`, документацию, имена файлов или коммиты.
- **Данные банка.** Реальные имена, счета и платежи из
  `одна из экранных форм VTB Business.pptx` в демо не переносить (БТ, раздел 1).
- **Помощник.** Не выполняет банковские операции, не запрашивает пароли и коды,
  не выдумывает тарифы и инструкции банка. Отвечает только по базе знаний,
  при отсутствии данных направляет в поддержку (AI-04, AI-05).
- **Цены и скидки.** Не выдумывать. Где условия неизвестны — «уточняются
  у поставщика» (CONTENT-01).
- **S05 «Страхование».** Намеренно без кнопки перехода и без указания
  страховщика. Это согласованное исключение, не баг.

## Текущее состояние

Типы проходят, 3 теста зелёные. Каталог, карточки, вход, контакты и чат собраны.
Значки Telegram/WhatsApp — статические, без перехода (BT, Изменение 1.1).

Открыто:

1. **Проверить AI end-to-end.** В `.env` стоит `OPENAI_MODEL=gpt-4o-mini`,
   ключ заполнен, но живой ответ ни разу не получен. Сервер использует
   Responses API (`client.responses.create`). Если 502 — смотреть
   `[assistant] Ошибка провайдера` в консоли сервера. Закрывает AC09.
2. **Оптимизировать картинки.** `public/images/*.png` весят 8.1 МБ, по 1.2 МБ
   на карточку. VISUAL-01 требует оптимизации для браузера. Пережать в WebP
   с PNG-фолбэком, цель — до ~150 КБ на изображение.

Отложено для MVP (BT, Изменение 1.1):

- **AC02 — сверка входа с эталоном.** Поэлементное сравнение при 1440×900,
  масштабе 100%, языке RU. Вход ограничен парой `klim` / `klim`.
- **Контакты Telegram/WhatsApp (AC08).** Значки статические. Когда банк даст
  адреса — хранить в переменных окружения, значки делать ссылками по https
  на подтверждённые хосты (BT: CONTACT-02).
