# Partner pannel

Локальная витрина партнёрских сервисов VTB Kazakhstan. Основа разработки — [согласованное БТ](docs/BT.md).

## Запуск

Node.js 22.17+ (или совместимый с Vite 7), npm.

```powershell
npm install
npm run dev
```

Откройте http://localhost:5173. Демо-вход: `klim` / `klim`. API запускается на `127.0.0.1:3001`.

```powershell
npm run build
npm test
# После сборки один сервер обслуживает и API, и фронтенд:
npm start
```

После `npm start` откройте http://localhost:3001.

## Настоящий AI

Скопируйте `.env.example` в `.env`. Укажите `OPENAI_API_KEY` и `OPENAI_MODEL` (доступную в вашем API-аккаунте модель). Перезапустите сервер. Ключ остаётся на сервере, `.env` исключён из Git. Интеграция использует OpenAI Responses API; провайдер можно заменить в `server/app.ts`.

Без ключа/модели чат показывает честное сообщение о необходимости подключения, не имитирует ответ AI. Живые ответы требуют интернета и доступного API-баланса. В `server/knowledge.ts` находится стартовая база: использование витрины, ссылки на официальные инструкции, контакты поддержки, описания сервисов. Полные утверждённые банковские инструкции необходимо добавить перед приёмкой полноценной помощи по операциям VTB Business.

Значки Telegram и WhatsApp под сеткой статические, без перехода: контакты банка для MVP не предоставляются (BT: CONTACT-01, CONTACT-02). У страхования намеренно нет ссылки и кнопки подключения.

## Устройство

- `src/` — React-интерфейс, анимации и HTTP-адаптер каталога.
- `server/` — API, локальные сессии, интеграция AI, база знаний.
- `shared/` — общие типы, контракт данных.
- `public/login/` — локальная копия стартовой страницы и локальный вход.
- `public/reference/` — исходные стили и графика банковской страницы.
- `public/images/` — семь оригинальных 3D-иллюстраций ImageGen.
- `docs/` — БТ и журнал реализации.

`npm run capture:reference` повторно скачивает общедоступный эталон входа и ресурсы (RU/EN/KZ). Не запускайте без необходимости: это обновляет закреплённую ленту новостей. Скрипт удаляет банковские скрипты и скрытые токены, добавляет локальную авторизацию. Исходный логотип не перерисовывается.

Сервер слушает только loopback. Демонстрационные учётные данные и сессии не предназначены для производственного размещения. Загруженные пользовательские PPTX со скриншотами банковских данных исключены из Git.
