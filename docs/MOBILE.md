# Мобильная версия

Адаптация включается при ширине окна до 800 CSS-пикселей.
Компьютерная версия сохраняет прежнюю компоновку.

- Общая навигация: раскрывающееся меню, вложенные пункты внутри потока,
  без выпадения за край экрана, увеличенные области нажатия.
- Главная: читаемые шрифты и кнопки, перенос панели действий;
  счета и платежи прокручиваются горизонтально внутри таблицы.
- Партнёрские сервисы: одна колонка на телефоне, раскрытие нажатием,
  увеличенные кнопки и текст условий.
- Чат: ограничен шириной и динамической высотой экрана, поле ввода 16px.
- POS: одна колонка, изображение без обрезки, кнопка по ширине.
- Заявка: модальное окно в пределах экрана, закреплённые действия,
  увеличение документа с отдельной прокруткой, ссылка на PDF.
- RU/EN/KZ вход: общая мобильная таблица стилей, подписи над полями,
  новости и контакты в потоке вместо фиксированного подвала.

Проверены TypeScript, сборка и существующие API-тесты. Проверка на реальных
телефонах и экранной клавиатуре остаётся отдельным этапом приёмки.

Сервер по-прежнему слушает только 127.0.0.1. Ссылка localhost на телефоне
не ведёт на компьютер: для физического телефона требуется отдельная
настройка доступа по локальной сети или защищённое тестовое размещение.
Эта доработка не открывает сервер в сеть и не меняет правила доступа.
