# Главная страница · 16.09.2026

Запрос: отдельная главная страница по предоставленному скриншоту VTB Business,
без двух баннеров с флагами и надписью «Құрылтай». Остальной проект не менять.

- Адрес: `/home`, доступ после существующего демонстрационного входа.
- Сохранены порядок разделов, плотная табличная компоновка, светлая шапка,
  горизонтальное меню, синие элементы управления и чередование строк.
- Баннерный блок удалён без пустого места; раздел новостей следует за меню.
- Организация, пользователь, счета и операции — демонстрационные.
- «Продукты и услуги» открывает существующий `/panel`.
- После «Письма» добавлен пункт «Партнерские сервисы»: открывает `/panel`
  в той же вкладке с общей существующей сессией. Обе страницы — один проект.
- Существующие `/panel`, авторизация, AI и стили панели не менялись.
  Автоматический переход после входа остаётся прежним; `/home` открывается отдельно.
- Сворачивание разделов и вкладки работают локально. Банковские действия
  показывают уведомление о демонстрационном режиме, а не выполняют операции.
- Изображение-эталон с банковскими данными не копируется в публичный репозиторий.

Файлы: `src/Home.tsx`, изолированные стили `src/home.css`, выбор страницы
в `src/main.tsx`. Это воспроизведение по растровому скриншоту, без доступа
к исходной разметке внутреннего банка; пиксельное совпадение не подтверждено.
